# Instructions for Coding Agents

## Documentation

Follow [docs/DOCUMENTATION_STYLE.md](docs/DOCUMENTATION_STYLE.md) for every
Markdown change. In short:

- Instruction first, reason second; at most 80 words per paragraph.
- State a page's validation status once. Do not add a caveat to every section.
- Keep test evidence, commit hashes, CI run IDs and PR numbers out of user
  guides; put evidence in `docs/evidence/`.
- When a review asks for a clarification, replace or shorten existing text
  rather than appending another qualifier.
